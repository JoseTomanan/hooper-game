# Canonical agent-skill policy

`.agent-skills/canonical/` is the only authoring source for the mirrored skill
trees. Run `python tools/sync_agent_skills.py generate` after editing it. Never
edit `.agents/skills/` or `.claude/skills/` directly.

The manifest classifies every output:

- `shared` renders byte-identically for every platform;
- `generated` uses small adapter values or explicit platform sections, with a
  required `difference_reason` explaining why the outputs differ;
- `platform-specific` uses an explicit source per platform when a file has no
  meaningful shared body, with a required `difference_reason`.

Use `{{adapter_key}}` for short substitutions. Use
`<!-- agent-skill:if platform -->...<!-- agent-skill:endif -->` only when the
runtime instructions genuinely differ. Product naming, tool syntax, agent
paths, configured model labels, and command syntax belong in adapter files;
domain and process policy does not.

Volatile measurements must not masquerade as timeless operating instructions.
Prefer a live command over a frozen count. When a historical count, date, path,
or issue state is important, date-stamp it and place its re-verification command
beside the claim. `check` applies the manifest's known-stale patterns in addition
to verifying generated bytes and complete classification.

Commands:

```text
python tools/sync_agent_skills.py generate
python tools/sync_agent_skills.py check
python tools/sync_agent_skills.py report
```
